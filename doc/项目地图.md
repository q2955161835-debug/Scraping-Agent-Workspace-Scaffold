# 项目地图

## 工作区目标
- 本工作区用于管理多目标数据爬取项目，包括变量确认、渠道拆分、网页抓取、数据清洗、质量分级和最终交付。
- 工作区级规则由根目录 `AGENTS.md`（代理说明文件）维护。

## 根目录职责
- `AGENTS.md`：工作区级 `agent`（代理）规则、爬取流程、目录规范和质量分级。
- `doc/`：工作区级长期文档和阶段进展。
- `tools/`：工作区工具库，包含常用技能软连接、复用脚本和工作区专用技能。
- `.gitignore`（Git 忽略规则）：保护 `.env`（真实环境变量账本）和常见缓存文件。
- `.env.example`：环境变量示例账本；当前暂无必需变量。
- 第一层目标目录：每个爬取目标一个独立子项目。

## 子项目默认结构
- `目标项目/`：放最新版交付数据，例如 `latest.xlsx`、`latest.csv`、`latest.jsonl`。
- `目标项目/doc/`：放子项目进展记录、项目地图、目录说明、变量表说明、采集策略。
- `目标项目/旧数据/`：放被替换的历史版本。
- `目标项目/原始数据/`：放原始结构化抓取结果。
- `目标项目/原始文件/`：放下载的网页、附件、截图、报告、`PDF`（便携式文档格式）等源文件。
- `目标项目/try/`：放测试、调试、临时验证文件。

## 可扩展目录
- 子项目可按目标新增 `清洗数据/`、`脚本/`、`截图证据/`、`中间结果/`、`配置/`、`导出报告/` 等目录。
- 新增目录必须在子项目 `doc/项目地图.md` 或 `doc/目录说明.md` 中说明用途、可删除性和是否承载最终数据。

## 核心流程
1. 创建目标子项目目录。
2. 先建立变量确认表，列明变量名、含义、单位、类型、来源优先级、必填性、清洗规则和可接受缺失条件。
3. 生成未填数据的初始表格并等待用户确认。
4. 按渠道派遣子 `agent`（代理），并使用 `Scrapling`（网页抓取库）、`Excel`（表格）等技能执行采集和整理。
5. 原始结果入 `原始数据/` 或 `原始文件/`。
6. 清洗、合并、去重、质量分级后，把最新版数据放入子项目根目录。
7. 更新子项目和必要的工作区进展记录。

## 常用命令
- `git status --short --branch`：查看 `Git`（版本控制）状态。
- `git log --oneline --decorate -5`：查看最近提交。
- `rg --files`：快速列出文件。
- `rg "关键词"`：快速搜索文本。

## 关键依赖与技能
- `Scrapling`（网页抓取库）：网页抓取、动态页面、复杂访问场景、分页和爬虫框架。
- `mcporter`（模型上下文协议调用器）：调用 `Scrapling MCP`（Scrapling 模型上下文协议服务器）。
- `Excel`（表格）：变量确认表、初始空表、质量分级表和验收表。
- `external-skills-hub`（外部技能路由）：选择本地扩展技能。

## tools 工具库
- `tools/skills/scrapling`：链接到 `Scrapling`（网页抓取库）技能。
- `tools/skills/spreadsheets`：链接到 `Spreadsheets`（表格）技能。
- `tools/skills/markitdown-skill`：链接到文档转 Markdown（标记文本）技能。
- `tools/skills/multi-search-engine`：链接到多搜索引擎技能。
- `tools/skills/external-skills-hub`：链接到外部技能路由。
- `tools/skills/skill-creator`：链接到技能创建器。
- `tools/scripts/New-ScrapingProject.ps1`：创建目标子项目目录骨架。
- `tools/scripts/New-VariableTemplate.ps1`：创建空白变量确认表。
- `tools/scripts/Test-ScrapingWorkspace.ps1`：检查工作区规则文件、技能软连接和根目录杂项文件。
- `tools/workspace-scraping/SKILL.md`：本工作区专用技能细则。

## 环境账本
- `.env` 保存真实敏感配置，必须被 `.gitignore`（Git 忽略规则）忽略。
- `.env.example` 只保存变量名、占位值和说明；新增、删除或改名环境变量时同步维护。
- 当前工作区暂未定义必需环境变量。
