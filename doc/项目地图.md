# 项目地图

## 工作区目标
- 当前工作区目录名为 `数据爬取 Agent 工作区脚手架`。
- 本工作区用于管理多目标数据爬取项目，包括变量确认、渠道拆分、网页抓取、数据清洗、质量分级和最终交付。
- 工作区采用“工作区外壳包裹脚手架”的结构：根目录承载实际子项目，`脚手架/` 承载可复用能力。
- `Scrapling`（网页抓取库）仍是网页采集核心准则，整合其他项目时不得改变这一主流程。

## 根目录职责
- `AGENTS.md`：工作区级 `agent`（代理）规则、爬取流程、目录规范、质量分级和脚手架边界。
- `README.md`：当前工作区结构说明。
- `doc/`：工作区级长期文档和阶段进展。
- `脚手架/`：独立脚手架目录，包含模板、示例、脚本、测试、发布说明和工作区专用技能。
- `agent-reach/`：已创建的整合子项目入口，等待导入原始项目内容。
- `try/`：工作区级临时验证目录。
- `.gitignore`（Git 忽略规则）：保护 `.env`（真实环境变量账本）、缓存和本地技能软连接。
- `.env.example`：工作区环境变量示例账本；当前暂无必需变量。

## 子项目默认结构
- `目标项目/`：放最新版交付数据，例如 `latest.xlsx`、`latest.csv`、`latest.jsonl`。
- `目标项目/doc/`：放子项目进展记录、项目地图、目录说明、变量表说明、采集策略。
- `目标项目/旧数据/`：放被替换的历史版本。
- `目标项目/原始数据/`：放原始结构化抓取结果。
- `目标项目/原始文件/`：放下载的网页、附件、截图、报告、`PDF`（便携式文档格式）等源文件。
- `目标项目/try/`：放测试、调试、临时验证文件。

## 可扩展目录
- 子项目可按目标新增 `清洗数据/`、`脚本/`、`截图证据/`、`中间结果/`、`配置/`、`导出报告/` 等目录。
- 新增目录必须在子项目 `doc/项目地图.md` 或 `doc/目录说明.md` 中说明用途、可删除性和是否承载最终数据。

## 核心流程
1. 创建目标子项目目录。
2. 先建立变量确认表，列明变量名、含义、单位、类型、来源优先级、必填性、清洗规则和可接受缺失条件。
3. 生成未填数据的初始表格并等待用户确认。
4. 按渠道派遣子 `agent`（代理），并使用 `Scrapling`（网页抓取库）、`Excel`（表格）等技能执行采集和整理。
5. 原始结果入 `原始数据/` 或 `原始文件/`。
6. 清洗、合并、去重、质量分级后，把最新版数据放入子项目根目录。
7. 更新子项目和必要的工作区进展记录。

## 脚手架目录
- `脚手架/README.md`：脚手架入口说明和快速开始。
- `脚手架/AGENTS.md`：脚手架内置工作流规则，供复制或发布脚手架时使用。
- `脚手架/tools/`：工具库，包含常用技能软连接、复用脚本和工作区专用技能。
- `脚手架/templates/`：标准爬取子项目模板。
- `脚手架/examples/`：`Scrapling`（网页抓取库）示例代码。
- `脚手架/tests/`：脚手架结构测试。
- `脚手架/.github/workflows/`：脚手架发布仓库使用的 GitHub Actions（GitHub 自动化流程）校验模板。

## 当前子项目
- `agent-reach/`：整合占位子项目。当前未定位到原始 `agent-reach`（代理触达项目）目录，已先建立标准目录和整合说明，后续导入时必须保留 `Scrapling`（网页抓取库）优先的采集流程。

## 常用命令
- `git status --short --branch`：查看 `Git`（版本控制）状态。
- `git log --oneline --decorate -5`：查看最近提交。
- `rg --files`：快速列出文件。
- `rg "关键词"`：快速搜索文本。
- `cd 脚手架; python tools/scripts/validate_workspace.py .`：检查脚手架结构。
- `cd 脚手架; python tools/scripts/scaffold_project.py "目标项目" --root ..`：从脚手架在工作区根目录创建目标子项目。

## 关键依赖与技能
- `Scrapling`（网页抓取库）：网页抓取、动态页面、复杂访问场景、分页和爬虫框架。
- `mcporter`（模型上下文协议调用器）：调用 `Scrapling MCP`（Scrapling 模型上下文协议服务器）。
- `Excel`（表格）：变量确认表、初始空表、质量分级表和验收表。
- `external-skills-hub`（外部技能路由）：选择本地扩展技能。

- `脚手架/tools/skills/markitdown-skill`：链接到文档转 Markdown（标记文本）技能。

- `脚手架/tools/skills/external-skills-hub`：链接到外部技能路由。
- `脚手架/tools/skills/skill-creator`：链接到技能创建器。

- `脚手架/tools/scripts/New-VariableTemplate.ps1`：创建空白变量确认表。
- `脚手架/tools/scripts/Test-ScrapingWorkspace.ps1`：检查脚手架规则文件、技能软连接和根目录杂项文件。

- `脚手架/tools/scripts/create_variable_template.py`：跨平台创建空白变量确认表。

## 环境账本
- `.env` 保存真实敏感配置，必须被 `.gitignore`（Git 忽略规则）忽略。
- `.env.example` 只保存变量名、占位值和说明；新增、删除或改名环境变量时同步维护。
- 当前工作区暂未定义必需环境变量。
