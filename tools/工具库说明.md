# tools 工具库说明

## 用途
- `tools/`（工具库）存放本工作区常用技能软连接、可复用脚本和工作区专用技能。
- 工具库服务于实际爬虫任务，优先减少重复建目录、重复建变量表、重复做结构检查。

## 目录
- `skills/`：常用技能软连接库，链接到外部或系统技能目录。
- `scripts/`：实际爬虫任务常用复用脚本。
- `workspace-scraping/`：本工作区专用 `skill`（技能），用于指导子项目创建、变量确认、渠道派遣和数据验收。

## 软连接管理
- 软连接命名应与原技能名保持一致或保持可识别。
- 新增技能软连接时，需要确认目标路径存在，并在 `doc/项目地图.md` 中更新工具库清单。
- 若软连接目标路径失效，优先修复链接目标，不复制整个技能目录。
- GitHub（代码托管平台）仓库不提交指向本机绝对路径的软连接；其他机器需要运行 `tools/scripts/Link-Skills.ps1` 重建本地链接。

## 可复用脚本管理
- 脚本必须只处理工作区内的项目结构、变量表、检查任务或中间文件整理。
- 脚本参数必须明确，避免依赖当前目录猜测危险路径。
- 新增脚本后，在本文件和 `tools/workspace-scraping/SKILL.md` 中补充用途。

## 脚本清单
- `scripts/scaffold_project.py`：跨平台创建目标子项目目录骨架。
- `scripts/create_variable_template.py`：跨平台创建空白变量确认表。
- `scripts/validate_workspace.py`：跨平台检查脚手架结构。
- `scripts/New-ScrapingProject.ps1`：Windows（微软视窗系统）版子项目创建脚本。
- `scripts/New-VariableTemplate.ps1`：Windows（微软视窗系统）版变量确认表脚本。
- `scripts/Test-ScrapingWorkspace.ps1`：Windows（微软视窗系统）版结构检查脚本。
- `scripts/Link-Skills.ps1`：Windows（微软视窗系统）版常用技能软连接重建脚本。
