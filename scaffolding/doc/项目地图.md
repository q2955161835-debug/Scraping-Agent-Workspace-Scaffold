# 脚手架项目地图

## 目标
- 本目录是数据爬取工作区的独立脚手架，提供可复用规则、模板、脚本、示例和测试。
- 脚手架服务于上一级工作区或独立复制后的新工作区。
- `Scrapling`（网页抓取库）是脚手架内置网页采集核心准则。

## 目录职责
- `AGENTS.md`：脚手架内置工作流规则。
- `README.md`：脚手架说明和快速开始。
- `tools/`：工具库，包含脚本、技能软连接说明和 `workspace-scraping`（工作区爬取）技能。
- `templates/`：标准爬取子项目模板。
- `examples/`：`Scrapling`（网页抓取库）示例。
- `tests/`：结构测试。
- `.github/workflows/`：脚手架发布仓库可用的 GitHub Actions（GitHub 自动化流程）模板。

## 常用命令
- `python tools/scripts/validate_workspace.py .`：校验脚手架结构。
- `python tools/scripts/scaffold_project.py "目标项目" --root ..`：在上一级工作区创建子项目。
- `python tools/scripts/create_variable_template.py "../目标项目"`：为上一级工作区子项目创建变量确认表。
