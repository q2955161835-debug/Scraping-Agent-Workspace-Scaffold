# Dataset Acceptance（数据验收）

## Required Checks（必查项）
- 变量确认表已经由用户确认，且正式数据字段没有绕过确认流程新增。
- 子项目 `doc/任务清单.md` 已记录访问过的 URL（统一资源定位符）、文件、接口或文献任务，并包含去重键、状态、输出位置和失败项。
- 多子 `Agent`（代理）任务已按来源等级注入 `subagent-prompt-templates.md` 中的对应提示词模板。
- 最终数据包含来源字段、质量等级字段、采集时间字段和核验状态字段。
- 最新版数据位于子项目根目录。
- 原始结构化结果位于 `原始数据/`，原始文件或截图位于 `原始文件/`。
- 被替换的数据进入 `旧数据/`，文件名包含日期、版本号或数据周期。

## Missing Data（缺失数据）
- 必填字段缺失时，记录缺失原因、已尝试渠道和下一步建议。
- 可接受缺失字段按变量确认表中的“可接受缺失条件”处理。
- 逆向计算字段必须记录公式、输入来源、计算时间范围和误差风险。

## Handoff（交付）
- 最终交付前运行 `tools/scripts/Test-ScrapingWorkspace.ps1` 检查工作区结构。
- 子项目 `doc/进展记录.md` 写明本阶段完成内容、文件清单和错误汇报。
- 汇总说明只引用必要证据，不复制大段网页或文档内容。
