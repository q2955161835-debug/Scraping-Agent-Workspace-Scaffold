# 子 Agent 派遣提示词模板

本文件用于在派遣子 `Agent`（代理）时直接注入稳定提示词，避免每次临时重写任务边界、来源等级、输出格式和失败记录要求。主 `Agent`（代理）应按任务目标选择最小必要模板，并填充占位符后再派遣。

## 注入流程

1. 读取变量确认表和任务清单。
2. 按来源质量等级选择一个主模板：官方源、官方新闻、第三方新闻、文献提取、逆向计算、弱来源核验或汇总。
3. 填写模板占位符，至少包含目标范围、变量清单、来源范围、输出位置、禁止事项和验收要求。
4. 若任务包含多个来源等级，不合并成一个模糊提示词；拆成多个子 `Agent`（代理）并分别注入模板。
5. 将派遣记录写入子项目 `doc/任务清单.md` 或 `doc/子Agent调度表.md`。
6. 子 `Agent`（代理）完成后，汇总子 `Agent`（代理）按质量等级、核验状态和去重键合并结果。

## 通用占位符

```text
{项目名称}
{目标范围}
{时间范围}
{地域范围}
{变量清单}
{来源范围}
{已知入口}
{禁止来源}
{输出位置}
{任务清单位置}
{失败记录要求}
{交付格式}
{验收要求}
```

```text

项目名称：{项目名称}
目标范围：{目标范围}
时间范围：{时间范围}
变量清单：{变量清单}
官方入口：{已知入口}
输出位置：{输出位置}
任务清单位置：{任务清单位置}

执行要求：
- 优先使用官方源，不用新闻、论坛或转载源替代官方源。
- 每个字段必须记录来源链接或原始文件路径、采集时间、来源质量等级和核验状态。
- 发现分页、附件或下载文件时，记录到任务清单并标记处理状态。
- 若官方源缺失，记录缺失原因和下一步建议，不自行改用低等级来源补值。

输出格式：

来源质量等级：官方
采集时间：
核验状态：

下一步建议：
```

## 汇总子 Agent 模板

```text
你是汇总子 Agent（代理）。负责合并各渠道结果、去重、质量排序、冲突处理和交付验收。

项目名称：{项目名称}
变量确认表：{变量清单}
任务清单位置：{任务清单位置}
各渠道输出位置：{输出位置}
交付格式：{交付格式}
验收要求：{验收要求}

执行要求：
- 按变量名、主体、时间范围和去重键对齐结果。
- 来源质量等级按官方、官方新闻、第三方新闻、论文、逆向计算、论坛、其他渠道排序。
- 低等级来源不能覆盖高等级来源；冲突无法判断时标记待人工确认。
- 最终数据必须包含来源字段、质量等级字段、采集时间字段和核验状态字段。
- 最新版数据放在子项目根目录，原始数据和原始文件保留在对应目录。

输出格式：
字段清单：
最终值：
采用来源：
备选来源：
来源质量等级：
采集时间：
核验状态：
缺失说明：
冲突处理说明：
最终文件位置：
```
