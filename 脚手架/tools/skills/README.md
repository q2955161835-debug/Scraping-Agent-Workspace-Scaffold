# Skills Link Library（技能软连接库）

本目录用于本地放置常用 `skill`（技能）的软连接。GitHub（代码托管平台）仓库不提交指向本机绝对路径的软连接，避免其他机器 clone（克隆）后出现失效链接。

## 本地重建

在 Windows（微软视窗系统）中运行：

```powershell
.\tools\scripts\Link-Skills.ps1
```

默认尝试链接：

- `scrapling`
- `spreadsheets`
- `markitdown-skill`
- `multi-search-engine`
- `external-skills-hub`
- `skill-creator`
